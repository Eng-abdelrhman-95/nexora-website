NEXORA Website — Final package
================================

Contents
- index.html: responsive Arabic/English website
- assets/nexora-logo.png: supplied official logo asset, used without alteration
- assets/nexora-background.jpg: supplied official NEXORA background.

Included functionality
- Responsive navigation, mobile menu, smooth scrolling, active section indication, back-to-top
- Arabic/English language toggle
- Service-detail modal for each service
- Copy username/password buttons and show/hide password
- Contact form opens WhatsApp with a prefilled message; the visitor must review and send it
- Direct links to WhatsApp, catalog, Facebook, Instagram, TikTok, email, and selected NEXORA forms

Before publishing
1. Review every external URL and make sure it is still current.
2. Verify the demo login credentials still work. They are visible in the website source and must belong only to a demo account with no sensitive data.
3. This is a static site. The contact form does not store submissions or send data to a backend.
4. Upload index.html and the entire assets folder to the website repository together. Do not upload index.html alone or the logo/background will not load.
5. Test on desktop and mobile after deployment. Verify all form URLs, social links, and the demo login destination.
6. If hosting with GitHub Pages, place index.html and assets/ in the published root (or the configured publishing folder), then commit and push both.

Brand basis
- Colors: #05070F, #29B6FF, #8B3FE8, #3E7BFA, card #0B1830, text #E9EEF7
- Arial-first typography; Arabic RTL / English LTR
- Official logo and background copied from the supplied NEXORA brand archive
